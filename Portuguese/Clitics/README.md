Language: Portuguese

Linguistic phenomena: Clitics positioning

Proclisis is allowed only in the presence of syntactic triggers (e.g. negation, preverbal adverbs, complementizers), while enclisis is treated as the default pattern.
The testsuite contains both grammatical and ungrammatical examples designed to verify the implemented constraints.

The covered phenomena include:

default enclisis;
proclisis after syntactic triggers;
embedded clauses;
topicalization;
incorrect clitic placement.
